# 一、项目背景

## 1.1 项目背景

日常生活中，不同用户之间存在消费优惠资源的不平衡。

一部分用户拥有优惠券、会员权益、团购资格、促销资格等优惠资源，但不一定能够充分利用。

另一部分用户有实际消费需求，却缺少相应优惠资源，无法以更低的价格完成消费。

例如：

- 用户 A 想点外卖，但没有优惠券。
- 用户 B 拥有外卖会员和优惠券，可以获得更低的下单价格。
- 用户 A 想购买某餐厅的团购套餐，但没有合适的团购资格。
- 用户 B 可以参与符合规则的团购活动，帮助 A 完成购买。

这两类用户之间存在一定的资源差异和信息差。

项目希望通过互联网平台，将拥有优惠资源的用户与有消费需求的用户进行撮合，让优惠资源得到更有效的利用。

## 1.2 核心问题

| 用户角色 | 当前问题 | 平台提供的价值 |
|---|---|---|
| 消费需求方 A | 有消费需求，但缺少优惠资源 | 找到拥有优惠资源的用户，降低消费成本 |
| 优惠资源方 B | 拥有优惠权益，但缺少变现渠道 | 利用符合规则的优惠资源获得收益 |
| 平台 | 双方缺少高效、可信的交易渠道 | 提供需求发布、资源发布、撮合、交易和信用管理 |

## 1.3 核心商业逻辑

平台不局限于某一种商品或消费场景。

平台的核心是：

**让拥有优惠资源的人与需要优惠资源的人建立交易关系，通过撮合交易创造双方价值。**

核心参与者：

- A：有消费需求，希望获得优惠。
- B：拥有优惠资源，愿意提供代下单、代购或其他合规服务。
- 平台：提供信息撮合、交易管理、信用体系和纠纷处理。

核心原则：

1. A 和 B 可以互不认识。
2. 平台负责匹配双方需求。
3. B 不一定需要转让优惠券，可以在符合规则的前提下使用自己的优惠权益提供服务。
4. A 与 B 协商交易价格和服务费用。
5. 同一用户可以同时拥有 A 和 B 两种身份。
6. 不同消费场景可以采用不同的交易流程。

# 二、产品定位

## 2.1 产品定位

惠搭是一个基于消费需求和优惠资源的 C2C 撮合交易平台。

平台连接两类用户：

- 有消费需求、希望降低成本的用户。
- 拥有优惠资源、希望通过提供服务获得收益的用户。

平台通过标准化的交易流程，让双方能够完成消费优惠撮合。

## 2.2 产品核心价值

### 对 A：降低消费成本

A 可以发布自己的消费需求，寻找拥有相应优惠资源的 B。

例如：

某餐厅套餐：

- 商品原价：100 元。
- B 通过符合规则的团购活动获得优惠，实际成本：65 元。
- A 向 B 支付：80 元。
- A 节省：20 元。
- B 获得：15 元毛收益。

### 对 B：让优惠资源产生价值

B 可以利用自己已有的优惠资源，在平台上寻找有需求的用户。

例如：

- B 拥有会员权益。
- B 可以参与某项团购活动。
- B 熟悉某个平台的优惠活动。
- B 愿意为其他用户提供代下单服务。

在符合相关平台规则的情况下，通过交易获得收益。

### 对平台：建立优惠资源交易市场

平台通过撮合供需双方，形成交易市场。

长期目标是让不同消费场景的优惠资源都能在平台上找到对应需求。


# 项目总结

惠搭不是一个单纯的外卖代下单平台，也不是传统的优惠券商城。

它的核心是建立一个连接消费需求和优惠资源的撮合交易市场。

**核心理念：让拥有优惠资源的人，帮助有消费需求的人，以更低的成本完成消费，并从中获得合理收益。**

平台的长期发展方向：

- 从单一消费场景扩展到多种消费场景。
- 从人工撮合发展到自动化智能撮合。
- 从个人之间的交易发展到个人、商家和平台多方合作。
- 从单纯的优惠交易发展为消费优惠资源服务平台。

**最终愿景：成为一个连接消费需求与优惠资源的综合性交易撮合平台。**
